# Anime Atlas

**Discover your next anime with advanced filters and catalogs from different regions.**

Anime Atlas is an alternative interface for exploring the Crunchyroll catalog, designed to make anime discovery more practical and flexible. With advanced search, customizable filters, and regional catalog navigation, the project gives users more control over how they find titles to watch.

## Temporary demo

[Open Anime Atlas](https://anime-atlas-ehpe.onrender.com).

This public demo is a temporary proof of concept. The catalog will not be updated for now; data collection and database creation will be handled by a separate project. User accounts and lists may be deleted periodically. Do not use a password that you use for other services.

## Features

- **Advanced search:** search by title, genre, or synopsis.
- **Combinable filters:** narrow results by year, tags, content rating, content descriptors, audio language, subtitle availability, minimum rating, status, and other available criteria.
- **Customizable filters:** tailor search criteria to match your preferences.
- **Regional catalogs:** browse catalogs from different regions whose data has been collected and added to the database.
- **Audio and subtitle filters:** select specific audio languages and filter titles by subtitle availability.
- **Watched list:** keep track of anime you have watched.
- **Watchlist:** maintain a list of titles you plan to watch.
- **Anime details:** view information about individual titles.
- **Search, sorting, and pagination:** explore the catalog without loading every record at once.

## Regional catalogs

Anime availability, audio languages, and subtitles can vary by region. Anime Atlas allows users to browse regional catalogs included in its database, providing a broader view of available titles.

Regional coverage depends on the data collected and maintained by the project. Additional regions can be added as new catalogs are collected and processed.

## How it works

The application uses a FastAPI backend to query and serve catalog data. Search, filtering, sorting, and pagination operations run directly against SQLite, avoiding the need to load the entire catalog into memory.

The data is provided by the [`anime-data`](../anime-data) project, which maintains the catalog in a normalized SQLite database.

## Running locally

### Prerequisites

- Python installed.
- An `anime-data.db` database generated by the `anime-data` project, or another SQLite database compatible with the application's expected schema.

### Setup

The following commands are for Windows PowerShell.

1. Create and activate a virtual environment:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

3. Configure the database path if needed. By default, the application looks for `../anime-data/anime-data.db`.

   ```powershell
   $env:ANIME_DATABASE_PATH = "C:\path\to\anime-data.db"
   ```

4. Start the application:

   ```powershell
   uvicorn app.main:app --reload
   ```

### Access the application

- **Catalog:** http://127.0.0.1:8000
- **Interactive API documentation:** http://127.0.0.1:8000/docs

To allow access from other devices on your local network:

```powershell
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### Data validation and code quality

```powershell
python scripts/validate_data.py
pytest
ruff check .
ruff format --check .
```

The data validator checks for inconsistencies, such as mismatched record counts and duplicate IDs, without modifying the source data.

## API

| Endpoint | Description |
|---|---|
| `GET /` | Homepage |
| `GET /anime/{id}` | Anime details page |
| `GET /api/animes` | Lists anime with search, filters, and pagination |
| `GET /api/animes/{id}` | Returns details for a specific anime |
| `GET /api/filters` | Returns available filter options |
| `GET /api/categories` | Returns catalog tags |

Example request:

```http
GET /api/animes?q=action&year=2025&min_rating=4&page=1
```
